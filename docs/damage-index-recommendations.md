# 강화 전후 데미지 지수 비교

## 순차 스타포스 추천 (후속 변경)

장비군별 추천 상한: 에테르넬/광휘26, 칠흑25, 아케인셰이드/여명/마이스터링23, 기타22.
각 장비의 다음 1성만 후보로 노출하고 추천한 뒤 다음 단계 후보를 연다.
예를 들어 22→23 뒤의 23→24는 23성을 달성했다고 가정한 지수 비율과 추가 비용이다.
동일 아이템 스타포스가 연속하면 비용은 합산, 데미지 배율은 곱하여 마지막 목표 한 카드로 합친다.
사이에 다른 추천이 끼면 합치지 않는다. 합친 뒤 다시 정렬하지 않아 선행 조건을 보존한다.
이는 스타포스 체인별 조건부 추천이며, 다른 장비나 잠재 추천을 모두 달성한 전체 캐릭터의 동적 재최적화는 아니다.
사용자 시세 수정은 합쳐진 카드가 아닌 원래 단계별 비용을 재계산한 뒤 체인을 다시 구성한다.

표시 이름은 사용자 요청대로 **최종뎀**이다. 실제 최종 데미지 능력치의 %p 증가가 아니라,
고정한 프리셋에서 강화 전 대비 추정 데미지의 상대 증가율(%)을 뜻한다.

## 공통 전투 상태

`damage_index.boss_index`를 프리셋 선택 및 장착 가치에 사용한다.
스탯 항 × 버프 반영 공/마 × (1+(데미지+보공+설정 버프)/100) × 평균 크리티컬 배율 × 방어율 반영 배율.
기존에 공/마·크뎀은 API값, 스탯 항만 버프를 반영하던 불일치를 없앴다.
버프 설정은 복원한 올스탯0/공마355/크뎀54를 사용한다. 기존 시드링용 데미지30/보공75 가정도 공통 지수에 반영한다.
API에 이미 포함된 버프의 자동 식별은 여전히 지원하지 않는다.

`ReplacementModel`은 동일 상태의 상시 옵션을 제거·추가하여 지수 비율을 계산한다.
추천 대상 일반 장비의 잠재·추옵·스타포스는 데미지/보공/방무가 변하지 않으므로 그 배율은 약분된다.
고정 스탯과 %스탯, 고정 공/마와 공/마%, 크확과 크뎀의 곱연산 및 크확 상한을 반영한다.
부스탯은 개별 복원값을 우선 사용하며, 없으면 기존 환산 엔진의 부스탯 비율로 추정한다.

## 추천

- 스타포스: 현재/다음 성의 표 기반 증가량 차이를 적용. 비용 규칙 유지.
- 잠재: 기존 세 줄을 제거하고 각 새 구성에 대해 지수 증가 계산. 목표 이상 성공 결과의 확률 가중 평균 사용.
  기존 주스탯% 목표 구간·등급업 비용·천장·옵션 확률은 유지하고, 목표 선택의 목적함수만 최종뎀/비용으로 변경.
- 추옵: 기존 급수 분포와 비용 유지. 급수별 스탯 곱의 모멘트 10개를 누적하여
  전체 구성별 지수 증가의 정확한 조건부 평균을 계산한다(현재 확률 모델 내에서).
  반올림한 화면 목표가 아닌 원래 확률 판정 임계값을 사용한다.
- 쿨감·궁수 초과 크확: 기존 별도 환산분을 직접 비교 결과에 합산. `direct_with_skill_estimate` 표시.
- 시드링: 기존 극딜 비중·가동률 모델 유지. 데미지/보공 입력은 선택 프리셋의 투영값으로 통일.
- 특수 주스탯: 직접 비교 미지원 시 기존 환산 추정 유지, `legacy_special_stat` 표시.
- 새 옵션에 크확이 있어도 기존 상태가 100%라서 이를 버리지 않는다. 재설정으로 기존 크확을 잃는 경우를 계산한다.

프리셋은 추천 계산 도중 재최적화하지 않는다. 최종뎀은 정렬 전에 반올림하지 않는다.
백엔드와 프론트엔드는 모두 `damage_efficiency`(100억당 최종뎀)로 정렬한다.
사용자가 노작/연마석 가격을 바꿀 때도 동일하다. 주스탯%는 비교 증가율을 현재 주스탯1%의 효과로 나눈 표시값이다.
점수/등급 공식은 변경하지 않았으나 공통 지수 변경으로 선택 프리셋이 달라지면 그 결과는 달라질 수 있다.

## 검증

- 단위 테스트: 동일 옵션 0, 제거 손실, 복합 곱연산, 공통 지수와 일치, 크확 상한/손실,
  조건부 기대값, 축소된 추옵 표 전체 열거와 모멘트 결과 대조, 확률 분포 보존.
- Node 테스트: 최종뎀 정렬과 노작/연마석 사용자 시세 변경.
- 실제 조회: 2고스펙 63 / 1랭커 18 / 5세나 46개 행동. 추가 API 실패 없음, 유효 JSON 및 양수 이득/비용 확인.
  계산 시간 약 1.09 / .75 / .89초(네트워크 제외, 2026-11-05 조회).
- 실제 브라우저 시각 검증과 서버 재시작은 별도다.
