# 전투력과 보스전 효율의 경계

근거: 사용자가 제공한 게임 내 전투력 도움말 1~6쪽(2026-11-04 확인). 도움말은 규칙을 설명하지만 전체 계산식과 무기 환산표를 제공하지 않는다.

| 도움말 | 서비스 처리 |
|---|---|
| 1. 주·부스탯, 공/마, 데미지, 보공, 최종 데미지, 크뎀 사용. 레벨·방무·속성 내성 무시·포스 등 대상 의존 요소 제외 | API 전투력이 대표값이다. 방무·가상 보스 방어율은 보스전 프리셋 선택에만 쓴다. 현재 상대 추정식은 데미지·최종 데미지까지 복원한 공식식이 아니다. |
| 2. 무기 기본 공/마를 레벨 제한·등급 기준으로 변환하고 관련 추옵·스타포스를 재계산. 놀장 강화는 스타포스 재계산 예외 | 표준화 표가 없으므로 무기 또는 해당 강화 정보가 달라지면 추정을 생략한다. |
| 3. 데몬어벤져·제논은 전투력 구간에 따라 계수가 달라짐. 제로 보조무기의 일부 옵션과 아스트라 아워글라스의 기본 보공 제외 | 두 특수 직업 및 제로는 실측만 표시한다. 아워글라스 변경도 추정하지 않는다. 기본 보공 예외를 잠재 보공 전체 제외로 확대하지 않는다. |
| 4. 직업 간 비교에 무기상수를 직접 사용하지 않지만, 같은 직업의 사용 가능 무기 중 최고 무기상수를 기준으로 하위 무기를 보정 | 주무기 교체에 임의의 공통 배율을 쓰지 않는다. 직업·무기별 비교 규칙 검증 필요. |
| 5. 기본 능력치, 장비, 성향, 어빌리티, 하이퍼스탯, 유니온 공격대원·점령, 아티팩트, 헥사 스탯 포함. 일반 스킬(링크·길드 포함) 및 소비 아이템 제외 | 전투력 크뎀은 확인된 성장 출처만 합산한다. 보스전 효율 계산은 별도로 유지한다. 유니온 챔피언 휘장은 도움말에 별도 명시되지 않아 보류한다. |
| 6. 사용 중인 화살·표창·불릿, 정령/여제의 축복, 스타포스 컨버전, 파괴의 얄다바오트, 일부 이벤트 스킬은 예외 | 일반 스킬·소비품으로 일괄 차감하지 않는다. 적용 상태와 기여분을 확인하기 전 별도 합산하지 않는다. |

## 표시 및 한계

현재 전투력은 API 원본이다. 최적 프리셋 추정은 조회 시점 전투력과 간이식의 상대 변화율을 이용한 별도 참고값이다. API 최종 공격력·보공·스탯에는 발동 상태가 구분되지 않는 효과가 있을 수 있다. 크뎀을 출처별로 재구성한 것을 다른 입력까지 무버프로 복원한 것으로 해석하지 않는다.

샘플D(일리움) 11월 3일의 1,429,502,473은 스냅샷의 원본 전투력이다. 목표값에 맞추기 위해 직업별 계수를 조정하거나 링·노블레스 보공을 고정 차감하지 않는다. 다음 구현은 공식 입력별 성장 출처와 예외를 확보한 뒤, 무기 종류 및 강화 방식이 다른 실측 스냅샷에서 검증하는 것이다.
