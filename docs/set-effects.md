# 세트 효과 검증 및 프리셋 보정

## 적용 방식

1. 현재 착용 장비의 등록된 세트 소속을 합산합니다. 예비 특수 반지는 제외합니다.
2. Nexon `/character/set-effect`의 `total_set_count`와 대조합니다.
3. `set_option_full`에서 현재 개수로 활성화되는 단계가 `set_effect_info`와 일치하는지 확인합니다.
4. 선택 프리셋에서 새로 활성화되거나 빠지는 단계의 차이만 반영합니다. API 최종 스탯에 포함된 기존 세트를 다시 더하지 않습니다.
5. 공/마와 고정 스탯은 기본수치에, %는 배율에 적용합니다. 방무는 남은 방어율 비율을 곱하거나 나누어 교체합니다. 보공·크뎀·방무는 프리셋 조합 비교 지수에도 반영합니다.

단계 수치의 1순위는 실제 API의 전체 효과표입니다. 현재 착용하지 않아 응답에 없는 여명의 보스 세트는 [공식 도입 공지](https://maplestory.nexon.com/News/Update/656)의 2~4세트 효과를 사용합니다. 가디언 엔젤 링과 여명의 가디언 엔젤 링은 서로 다른 세트로 처리합니다.

## 검증 범위와 제한

현재 장비 매핑은 샘플B(나이트워커)·샘플C(엔젤릭버스터)·샘플A(칼리)의 검증 범위를 중심으로 등록했습니다. 칠흑, 여명, 광휘의 등록 장비와 에테르넬 도적/해적 방어구 및 검증된 데스티니 무기를 포함합니다. 보스 장신구·파티 퀘스트·마이스터는 등록한 일부 장비만 지원합니다. 마이스터의 미조회 단계는 추정하지 않으며 단일 부위 비활성 구간만 처리합니다.

**전 장비/럭키 아이템 규칙을 지원하는 범용 계산기가 아닙니다.** 알려진 데스티니 무기의 에테르넬 소속 외 임의 럭키 가산은 하지 않습니다. 새로운 교체 장비, 미지원 럭키 조합, 세트 단계 누락, 현재 API 불일치, 미지원 스킬형 효과가 있으면 해당 프리셋의 세트 차분 전체를 0으로 두고 이유를 표시합니다. 모르는 장비를 세트 없는 장비로 간주하지 않습니다. 같은 프리셋에서 변하지 않는 펫·캐시 세트는 API 기본값을 유지합니다.

현재와 다른 장비를 계산할 때 검증이 실패해도 조회 자체는 계속되지만 결과는 미보정 추정치입니다. `set_projection.status`는 `applied`, `verified_unchanged`, `unresolved` 중 하나이며 API 대조 목록, 세트 변화, 효과 증감, 실패 이유를 포함합니다. 결과 화면과 아이템 상세 환산 근거에서 확인할 수 있습니다.

## 2026-11-04 실제 API 회귀 검증

| 캐릭터 | 현재 장비의 재계산/API 일치 항목 | 선택 프리셋 세트 차이 |
|---|---|---|
| 샘플B(나이트워커) | 에테르넬 도적 8, 칠흑 5, 보스 장신구 1, 파티 퀘스트 1 | 칠흑 5→10, 여명 0→2; 나머지 변경은 활성 효과 없음 |
| 샘플C(엔젤릭버스터) | 에테르넬 해적 8, 칠흑 10, 광휘 4 | 없음, 기존 세트 재가산 없음 |
| 샘플A(칼리) | 에테르넬 도적 8, 칠흑 10, 광휘 4 | 없음, 기존 세트 재가산 없음 |

샘플B(나이트워커)의 세트 차분은 올스탯 +90, 공격력/마력 각각 +90, 보공 +30%p, 크뎀 +10%p, HP +2250, 남은 방어율 ×0.9였습니다. 방무 수치 자체에 10%p를 더하는 방식이 아닙니다.

API 스냅샷은 조회 시점에 따라 변합니다. 위 대조는 전체 참조 효율표 일치나 조건부 버프 정규화까지 검증했다는 뜻이 아닙니다. 조건부 효과 보정은 이번 작업에 포함하지 않았습니다.
