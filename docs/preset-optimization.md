# 저장 프리셋 조합 최적화

## 비교 범위

장비 1~3, 하이퍼스탯 1~3, 조회 가능한 유니온 프리셋(신규 state 방식은 최대 10개), 링크 1~3, 어빌리티 1~3을 조합합니다. 현재 상태도 후보로 유지합니다. 빈 저장 슬롯과 null 응답은 후보에서 제외하고, 동점이면 현재 상태를 우선합니다. 게임 내 설정이나 저장된 프리셋을 변경하지 않습니다.

유니온 신규 응답은 `union_state_stat` 및 `union_state_stat_preset`을 사용합니다. 구형 응답은 공격대원/점령 효과를 사용합니다. 아티팩트·헥사·직업 스킬 등은 현재 상태로 고정합니다.

## 비교 지수

`(주스탯 가중치 × 주스탯 + 부스탯) × 공/마 × (1 + (데미지 + 보공)/100) × 크리티컬 기대배율 × 방어율 배율`

- 크리티컬 기대배율: `1 + min(max(크확, 0), 100)/100 × (0.35 + 크뎀/100)`.
- 방어율 배율: `max(0, 1 - 3.8 × 남은 방어율 비율)`. 보스 방어율 **380%**를 비교용으로 가정합니다.
- 방무는 합산하지 않고 남은 방어율을 곱하여 기존 효과를 제거한 뒤 선택 효과로 교체합니다.
- 프리셋별 직접 확인 가능한 효과의 차이만 현재 API 수치에 반영합니다. 현재 효과를 다시 가산하지 않습니다.
- 고정 주·부스탯과 공/마, 스탯%, 크확·크뎀, 데미지·보공·방무를 반영합니다. 레벨당 잠재 옵션은 레벨을 구간으로 나눈 정수값을 사용합니다.
- 예비 특수 반지는 착용 스탯에 합산하지 않습니다.

## 한계와 표시

**이 지수는 실제 DPS가 아니며 참조 사이트의 최적화와 동일하지 않습니다.** 스킬별 점유율·버프 지속·쿨감·재사용·조건부 발동률·중첩·시드링 운용 등은 최적화하지 않습니다. 독립적으로 읽을 수 있는 상시 효과만 차분 적용하고, 처리하지 못한 문구는 `unmodeled_effects`에 남깁니다. 장비 변경 시 세트 효과는 현재 API 대조를 통과한 등록 규칙만 보정합니다([세트 효과 검증](set-effects.md)). 이 때문에 선택된 조합과 실제 보스전 최적 조합이 다를 수 있습니다.

특수 직업(HP/복수 주스탯), 복수 부스탯, 필수 보스 스탯 누락은 안전하게 기존 장비 잠재 점수 선택으로 대체합니다. 조합 최적화 완료로 표시하지 않습니다.

응답 `profile.optimization`에는 선택 번호, 비교 조합 수, 보스 방어율 가정, 현재 대비 지수 비율(실제 딜 상승률 아님), 미지원 문구 및 한계가 포함됩니다. 결과 화면과 아이템 상세의 환산 근거에서도 선택 기준을 확인할 수 있습니다.
